# git-flow

Read `.agents/agents/git-flow.md` and `.agents/rules/git-conventions.md`. Use `$git-conventional-commits` and `$git-pr-description` for their steps when installed. Inspect actual repository state before proposing branch, commit, or PR actions. Require explicit approval before push, tag, merge, or publish. Do not assume release skills exist; handle release decisions from the rule file. Report each completed action and its result.
