# code-init

Создаёт или дополняет корневой `AGENTS.md` для Codex. Выявляет реальные команды, проверки, структуру проекта и установленные skills; неизвестные сведения не выдумывает.

Вызов: `$code-init` или просьба настроить инструкции проекта для Codex.

В новом файле задаёт четыре правила: коммит делает пользователь; ответы краткие через `$caveman`, если skill установлен; комментарии в коде добавляются только при необходимости; ответы на русском. Существующий `AGENTS.md` читает и дополняет без потери локальных инструкций. При конфликте правил или запросе полной замены показывает конкретное изменение и запрашивает решение.

Разделы про `$code-plan`, `$code-build`, `$code-review`, `$code-debug` добавляет только при наличии соответствующих skills. Не обещает автоматический test gate или фиксированные модели; после правок требует запускать подходящие тесты и сообщать результаты. Не выполняет `git add` и `git commit`.
